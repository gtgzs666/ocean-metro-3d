# 海上列车 · 水平线

一辆贴着海面行驶的地铁，海面有实时平面反射，天空随**现实时间**变化。现在整体换成了二渲三（卡通描边）画风，并在车站之间加入了小岛、废弃车站和海上城镇。

## 运行

ES module 不能用 `file://` 直接打开，所以用项目自带的脚本起一个本地服务器：

```bash
cd projects/ocean-metro-3d
./start.sh
```

然后打开 <http://localhost:8123/>。

也可以手动：

```bash
python3 -m http.server 8123 --bind 127.0.0.1
```

Three.js r160 已经放在 `vendor/` 里，**不需要联网，也不依赖 CDN**。建议用 Chrome / Edge（需要 WebGL2）。

## 部署到 GitHub Pages

这是一个纯静态页面，所有依赖都在 `vendor/`，不需要构建，也没有后端。

1. 在 GitHub 新建一个空仓库（不要勾选自动生成 README）。
2. 在项目目录执行（把地址换成你的仓库）：

```bash
git init
git add .
git commit -m "Deploy ocean metro"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

3. 打开仓库的 **Settings → Pages → Build and deployment**，Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
4. 等 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

> 免费账号的 Pages 需要公开仓库；私有仓库需要 GitHub Pro / Team。页面需要 WebGL2，建议用 Chrome / Edge 打开。之后更新只需要 `git add . && git commit -m "update" && git push`，Pages 会自动重新发布。

## 操作

| 操作 | 效果 |
| --- | --- |
| `T` | 在“现实时间”和“加速时间（90 秒一整天）”之间切换 |
| `Esc` | 暂停列车并打开设置页 |
| 鼠标移动 | 轻微改变镜头位置，产生视差（开场镜头结束后生效） |

默认直接读取电脑的本地时间：清晨、正午、黄昏、深夜的天空与海面颜色、太阳/月亮位置、灯光强度都会跟着变。

设置页（`Esc`）里可以调帧率上限、渲染分辨率、阴影质量、泛光和**水面反射**开关，选项会自动保存在浏览器本地。

> 如果发现整片水面倒影突然消失，先检查 `Esc` 设置里的“水面反射”是否被关闭；关闭后会隐藏列车、月亮等平面倒影。前灯的两团眩光和水面的模糊灯光倒影仍然保留，它们不依赖平面反射。前灯只在 18:00–6:00 开启。

## 构图与开场

- 列车共 **5 节车厢**，从左向右行驶。
- 镜头在车身侧前方，用轻微 3/4 视角兼顾车头正面与车身侧面；**车头停在画面横向 2/3 的位置**，车身向左侧画外延伸，始终不露出车尾。
- 启动时镜头从车头位置向左横移：车头先从屏幕左边缘探出，最终整列车占据画面左侧 2/3。横移约 10 秒，缓出。
- 窗口比例变化时会重新计算视野宽度，车头仍保持在 2/3 处。

## 画面里有什么

- **二渲三**：列车、车站、沿线风景全部使用 4 阶明暗的 `MeshToonMaterial`，并叠加反向外壳描边；灯光保留暖色发光块，交给 Bloom。后期使用 4x MSAA 和轻微 unsharp mask，避免描边和细节发糊。
- **海面**：620×620 的非线性网格（近处密、远处疏），顶点波形 + 片元细碎波纹 + 菲涅耳 + 日光碎金 + 车轮尾流白沫；颜色做了轻微色阶化和提饱和，更接近手绘海面。
- **平面反射**：镜像相机 + 斜切近裁剪面，把列车、车站、天空、月亮一起倒映进水里；反射以 0.9 倍分辨率渲染，叠加随时间流动的波纹扰动和五点柔化采样，并修正了镜像相机的左右翻转；倒影会随水波和来往风景持续变化，不再是左右反的死镜面。
- **列车**：五节车厢，统一采用**圆角正方形截面**；日系电车方头驾驶室（黑色风挡、目的地 LED、头灯/尾灯、雨刷、排障器、车钩、侧面驾驶室窗）、绿色平顶盖、程序化车窗贴图（暖光车厢 + 乘客剪影）、转向架、车轮、车侧水雾；**每节车厢前后各一组受电弓**，升起后接触上方接触线；18:00–6:00 自动打开前灯，两个灯前有暖色眩光，水面映出两道模糊的灯光倒影；不再绘制扇形光锥。
- **车站**：每 **20–40 秒**经过一座（站间距约 400–800 米），站台、雨棚、吊灯、站名牌（程序化 canvas 文字）、长椅、自动售货机、撑伞的等车人；通过时会先播报“正在通过 · 本通过站”，等站台滑到车尾后方，再播报“下一站 · 下一站名”，顺序不会再倒过来。
- **沿线风景**：车站之间会不断飘过三类风景——带树、鸟居或灯塔的小岛；有人居住的海上城镇（高脚屋、钟楼、灯串、栈桥、渔船、晾衣绳）；以及屋顶塌了一半、站牌褪色的废弃车站。
- **接触网**：参考日系铁路常见样式，30 米一跨；两侧是带混凝土基础、黄黑警示带和杆号牌的锥形钢管门架柱，横梁为上下弦 + 竖杆 + 斜撑的桁架，带悬臂定位器、绝缘子和张力平衡块；接触线保持水平，承力索带垂度，吊弦连接，受电弓弓头与接触线保持接触。整段接触网随海面一起后退。
- **氛围**：太阳/月亮的日轮、月轮和光晕由天空 shader 绘制（不再叠加额外贴片）；夜空星点、边缘更清楚的积云 sprite、远处岛影、航道浮标、车尾水雾粒子、泛光 / 暗角 / 纸颗粒 / 轻微色阶化。

## 文件结构

```
index.html          页面、HUD、样式
js/main.js          渲染器、灯光、后期、时间、开场镜头与主循环
js/palette.js       现实时间 -> 天空/海水调色板、太阳/月亮方向
js/toon.js          二渲三材质、4 阶渐变、反向外壳描边
js/sky.js           天空 shader、星空、云层
js/water.js         海面 shader、平面反射
js/train.js         列车建模与车窗贴图
js/station.js       车站生成、描边与经过逻辑
js/catenary.js      接触网、门架电杆与接触线
js/scenery.js       小岛 / 废弃车站 / 海上城镇
js/props.js         浮标与远岛
js/spray.js         车轮水雾粒子
vendor/             three.js r160 + 后期处理 addons
```

## 调试

浏览器控制台里可以直接玩时间与镜头：

```js
__sea.setHour(18.2)              // 固定到黄昏，不再跟随现实时间
__sea.unpin()                    // 恢复跟随现实时间
__sea.spawnStation(10)           // 立刻在右侧 10 米处生成一座车站
__sea.spawnScenery('town', 100, -110)  // 生成城镇（kind: island / town / abandoned）
__sea.clearScenery()             // 清空沿线风景
__sea.skipIntro()                // 直接跳到最终构图
__sea.restartIntro()             // 回到开场镜头
__sea.setIntroTime(2.0)          // 跳到开场第 2 秒，查看车头正面
```

## 性能说明

为了画质没有做太多妥协：DPR 上限 2、2048 阴影贴图、60 万顶点海面、0.9 倍分辨率 HDR 反射、4x MSAA、UnrealBloom 泛光，加上五节车厢和沿线的描边网格。独立显卡/较新的核显上运行比较合适；如果卡，优先在 `Esc` 设置页里降低渲染分辨率、关掉水面反射或把阴影调到低；也可以把 `js/water.js` 里的 `SEG` 调低。调试时可以用 `__sea.lowfx()` 临时关掉反射、阴影和泛光。
